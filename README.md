## 一、作品

两件使用同一套视觉语言的作品：二十四道同心圆弧。

| 页面 | 作品名 | 类型 | 一句话 |
| --- | --- | --- | --- |
| `static.html` | 静帧 | 几何构成（静态） | 时间冻结在光圈最亮的一刻 |
| `dynamic.html` | 脉动 | 交互动态 | 光圈持续自转、呼吸，并被观看者扰动 |

### 静帧

画面只有几何：24 道圆弧、84 条放射细线、一层胶片颗粒。

- **圆的间距**向外递增（`radius = maxR * t^1.22`），所以越往外越疏，像光在空气里散开。
- **线宽**由 `sin(π·t^0.9)^1.4` 控制，中段最粗、内外两端收细，形成"呼吸"的节奏而不是等距的靶子。
- **缺口**：每道弧的起止角由噪声决定，没有一道是完整圆，画面因此是"打开"的。
- **纵深**：第 i 道弧的圆心比外一道偏 `(x +0.055·t^1.6, y −0.03·t^1.6)`，几十道叠起来就是一个浅隧道。
- 所有弧先画进离屏缓冲、模糊两遍再贴回作为辉光，然后再叠一遍清晰的弧身。

### 脉动

与静帧相同的 24 道弧，但由 `draw()` 每帧重绘：

- 弧的起止角随时间缓慢偏转（越靠外转得越快），半径以 0.55 rad/s 的频率起伏 ±1.2%。
- 圆心处一团光核按正弦轻微搏动。

## 二、技术说明

**运行环境**：p5.js 1.11.3（`p5.min.js` 已放在仓库根目录，离线也能打开，不依赖 CDN）。

**生成方式**

1. `for` 循环 + 参数化：24 道弧的所有属性（半径、线宽、透明度、起止角、圆心偏移）都由 `ringParams(i)` 依据序号 `i` 算出来，改一个数字就能重构整张画面。放射细线同理。
2. Perlin 噪声决定"不确定"的部分：每道弧的缺口角度来自 `noise(i*5.3, 8.1)`，保证随机但每次打开都稳定（固定 `noiseSeed`），不会每次刷新都变一副样子。
3. 发光：不是加滤镜，而是用 `blendMode(ADD)` + 加粗到 2~8 倍、透明度极低的同形弧堆出辉光，成本远低于实时模糊。
4. 运动全部走缓动：旋转用 `time * 常数`，呼吸用正弦，光标跟随用 `lerp(x, target, 0.045)`。没有任何一处是硬跳的，所以画面不会闪、不会抖。
5. 配色插值：按 `1 / 2 / 3` 切配色时不是直接换色，而是从当前颜色 `lerpColor` 到目标颜色（约 50 帧过渡），中途再切也不会闪。

**画布适配**（保证打开不出现滚动条、不错位）

```css
html, body { margin: 0; padding: 0; height: 100%; overflow: hidden; }
canvas { display: block; }   /* p5 的 canvas 默认是行内元素，会多出几像素基线空隙 */
```

`createCanvas(windowWidth, windowHeight)` + `windowResized()` 重算尺寸，页面任何缩放都不会出现滚动条。

**颜色控制**：全站只用 5 个颜色值（1 个底色 + 4 个前景色），三套配色各自也是 5 色。

| 用途 | 青光（默认） |
| --- | --- |
| 底色 | `#050810` |
| 冷（外圈） | `#12305A` |
| 主色 | `#2FBFA0` |
| 高光 | `#8AE6C0` |
| 暖（唯一暖色） | `#F0D8A8` |

冷色铺满全画面，唯一的暖色只出现在一道弧和圆心光核上 —— 冷暖对比明确，不是随手取色。

## 三、创作说明

**想法**：把"光"拆成一层一层的环，像相机光圈，也像水面被投石后散开的涟漪。每一道环都不完整 —— 有的缺了一大半，有的只剩一小段 —— 因为真实的光从来不是闭合的。圆心逐环偏移，于是这堆同心圆又不是平面的靶心，而是一个有纵深的浅隧道。

**构图**：圆心偏左下（0.40, 0.52），光圈在左上与下方铺满、在右侧收住，右侧留白给画面呼吸。最亮的三个位置依次是：圆心光核 → 中段最粗的那几道弧 → 第 18 道暖色弧，视线沿着这条路径从中心往外走。

**为什么用弧而不是实心圆**：实心圆会立刻变成一个"图形符号"（太阳 / 靶子），弧有断口，就有了时间和运动感，也更像光的残影。

**动态版想做的事**：让这堆弧"活"起来，但不是乱动 —— 自转、呼吸、被推开的幅度都被压到很小，速度以"几乎察觉不到"为准。观看者的操作（移动、点击）是唯一能把画面推离平衡的力量。

## 四、交互

| 操作 | 反馈 |
| --- | --- |
| 移动鼠标 | 整个光圈被光标牵引（缓动跟随，位移约为光标偏移的 10%） |
| 鼠标点击 | 从落点激起一圈涟漪，向外扩散，波前经过时把弧推开并留下两道亮环 |
| 键盘 `1` / `2` / `3` | 切换三套配色（青光 / 紫光 / 焰光），插值过渡 |
| 键盘 `S` | 保存当前画面为 PNG |
